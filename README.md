# 双渠道投票实时统计看板

统计「第二届综合交通运输大模型智能体创新应用大赛」两个投票渠道的实时票数与排名。

## 启动

双击 `启动看板.bat`（或在本目录执行 `node server.mjs`），然后浏览器打开：

**http://127.0.0.1:3456**

首次采集约需 30~60 秒（渠道一要开无头浏览器加载页面）。

## 两个渠道

| 渠道 | 平台 | 采集方式 | 覆盖范围 |
|---|---|---|---|
| 渠道一 | 中国交通报 H5（h5vote.newaircloud.com） | 本机 Chrome/Edge 无头浏览器加载页面读取 | 票数前 100 名（平台每个视图只放出 100 项，服务端拒绝翻页） |
| 渠道二 | 扬帆评选（votezx.com） | 直连接口 `api.votezx.com/api/vote/playersearch` | 全量 297 项 |

- 服务端每 60 秒采集一次；页面每 30 秒自动刷新。
- 「较上次」= 相邻两次采集之间的合计票增量。
- 两个渠道按项目编号（101、754、1007…）自动对齐合并；总榜 = 两渠道票数之和排序。
- 渠道一显示「未进前100」= 该项目不在渠道一的票数前 100 名里，不代表票数为 0。

## 文件

- `server.mjs` — 聚合服务（采集 + 合并 + HTTP）
- `index.html` — 看板前端
- `启动看板.bat` — 一键启动
- 依赖：`playwright-core`（驱动本机已装的 Chrome/Edge，无需另下浏览器）

## 备注

- 渠道一接口带请求签名 + 阿里云 WAF 反爬，纯协议方式会被拒（"无效的签名"），因此走真实浏览器采集；如遇网络波动单轮失败会自动重试，页面数据保留上轮结果。
